## ⚙️ How to Run Locally

### 1. Clone the repository
```
git clone https://github.com/Mohansingh-bit/portfolio.git
cd portfolio
```

### 2. Install dependencies
```
pip install -r requirements.txt
```

### 3. Run the app
```
python app.py
```

### 4. Open in browser
```
http://localhost:5000
```

---

## 📱 Test on Mobile

Make sure your phone and PC are on the same WiFi, then:

```
python app.py
```

Open on phone:
```
http://YOUR_PC_IP:5000
```

Find your IP with `ipconfig` in CMD.
